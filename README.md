# Aquascape.org

Aquascape.org adalah tempat buat kamu yang suka aquascape atau baru mau mulai. Kita bisa sama-sama menjelajahi ide desain, tanaman air, dan cara merawat ekosistem akuarium.

Lihat repositori kami untuk inspirasi dan materi seputar aquascape. Punya ide atau tips menarik? Yuk, berbagi lewat issue atau pull request!
